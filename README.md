# 🤖 CryptoBuddy - Your First AI-Powered Financial Sidekick! 🌟

CryptoBuddy is a beginner-friendly AI-powered chatbot that analyzes real-time cryptocurrency data and offers basic investment insights based on **profitability** (like price trends) and **sustainability** (such as energy efficiency and long-term potential).

This project was built as part of a Week 1 AI Assignment on the PLP Academy. It integrates simple AI decision-making, natural language understanding using NLTK, and real-time crypto data via the CoinGecko API. 📈💬

## 🔍 Features

- 💬 **Interactive Chatbot**: Chat with CryptoBuddy using everyday language!
- 📊 **Real-Time Crypto Data**: Prices, market caps, trends fetched via [CoinGecko API](https://www.coingecko.com/en/api).
- 🌿 **Sustainability Analysis**: Find the most eco-friendly cryptocurrencies.
- 💰 **Profitability Checks**: Learn which coins are trending and promising.
- 📉 **Graphing Capabilities**: Request live graphs of selected coin prices.
- ⚠️ **Ethics Alert**: Crypto is risky — always DYOR (Do Your Own Research)!

---

## 🛠️ Technologies Used

- **Python 3**
- **Google Colab**
- `requests` – for CoinGecko API calls
- `matplotlib` – for plotting real-time price trends
- `nltk` – for basic Natural Language Processing
- `datetime`, `time` – for timestamp handling
